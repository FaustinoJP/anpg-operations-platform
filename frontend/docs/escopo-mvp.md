# Escopo do MVP

## Objectivo

Apresentar uma plataforma web institucional para centralização, análise e reporte de dados sobre operações de sondagem, intervenção e abandono de poços, market share, contratos activos e gestão inicial de stock OCTG.

## Dashboards obrigatórios

1. Dashboard Operacional
2. Dashboard de Análise de Mercado
3. Dashboard de Gestão de Stock OCTG

## Módulos complementares

- Portal dos Operadores
- Submissões
- Relatórios
- Auditoria
- Utilizadores
- Configurações

## Dados da fase de protótipo

A versão actual usa dados simulados em `data/mockData.ts`. Na fase real, estes dados passam a vir de uma API e base de dados.

## Integrações previstas

- SAP
- WellView
- Power BI
- API REST para operadores
- Importação Excel e PDF
