# Fase 3 — Dashboard Geral, Submissões e Auditoria

Esta fase reforça o protótipo para apresentação executiva e demonstração funcional perante a ANPG.

## 1. Dashboard Geral Executivo

Foram adicionados:

- Centro executivo com índice de prontidão;
- KPIs consolidados de operações, contratos, stock, submissões, SLA e alertas;
- Resumo por domínio: Operacional, Mercado, Stock OCTG e Submissões;
- Painel de alertas executivos;
- Prioridades para a Direcção;
- Fluxo operacional proposto: submissão, validação, aprovação, dashboards, relatórios e auditoria.

## 2. Submissões

A página de submissões passou a incluir uma fila de validação demonstrável, com:

- Lista de ficheiros submetidos por operadores;
- Estados de validação;
- Prioridade e origem da submissão;
- Painel de detalhes da submissão;
- Indicador de completude;
- Número de inconsistências;
- Simulação de aprovação, rejeição e solicitação de correcção;
- Regras de validação e SLA de resposta.

## 3. Auditoria

A auditoria foi expandida para demonstrar rastreabilidade e conformidade:

- Registos recentes com utilizador, módulo, acção, objecto e resultado;
- Timeline de eventos críticos;
- Eventos por módulo;
- Estado de conformidade;
- Modelo de auditoria com rastreabilidade, segurança e conformidade.

## 4. Próximos passos técnicos

Na próxima fase, estas telas poderão ser ligadas a backend real com:

- API de submissões;
- Base de dados PostgreSQL;
- Armazenamento de ficheiros;
- Workflow real de aprovação;
- Logs imutáveis de auditoria;
- Exportações reais com templates institucionais.
