# Adaptação à identidade visual actual da ANPG

Esta versão actualiza o pacote completo para alinhar a interface com a identidade visual actual da ANPG:

- Uso predominante de vermelho ANPG, branco e tons charcoal/cinza.
- Remoção do visual institucional antigo baseado em azul escuro e dourado.
- Substituição dos logos antigos pelo novo wordmark vermelho.
- Sidebar clara, topbar clara e destaques activos em vermelho.
- Ilustração offshore ajustada para vermelho, mantendo o contexto Oil & Gas.
- Mantidas as funcionalidades existentes: login real, backend NestJS, PostgreSQL, Prisma, Swagger, dashboards, submissões e auditoria.
